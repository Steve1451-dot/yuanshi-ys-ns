## 行为

- 去掉左下角“原生手柄直通 / 等待云端确认”状态条。右上角触屏悬浮球、
  延迟显示、可选诊断与输入模式记录保持不变。
- 按住实体 ZL 后，只有体感生成的右摇杆等待 **100 毫秒**；不使用 sleep，
  不推迟物理按键、扳机或物理右摇杆。
- 实体 L（云端 LB）按住期间暂停体感，不论 B/X 与 LB 谁先按。
  LB 松开后若仍满足瞄准条件，重新等待 100 毫秒再恢复体感。
- 松开 ZL、UI 接管或输入切换时清除等待窗口；计时早于窗口起点时重新计时。
- 不采用“任意两个键同时按下就关闭体感”的规则，以免 ZL+射击无法瞄准。
- 原有轴方向、灵敏度、传感器新鲜度、物理摇杆优先及持久化格式不变。

当前使用标准 Xbox 物理位置布局：游戏提示 **LB+B = Switch L+A**，
**LB+X = Switch L+Y**。Switch 印字与游戏 Xbox 印字不同；本版未交换按钮。

## 新增安全计数

沿用已有每五秒快照，并在串流结束补一次累计值，无逐帧日志、账号或服务器内容。

| 事件 | 含义 |
| --- | --- |
| `INPUT_LB_B_SAMPLE_TICKS` / `INPUT_LB_X_SAMPLE_TICKS` | UI 原始采样见到组合键的帧数，包含被 UI 接管的输入 |
| `INPUT_LB_B_SEND_TICKS` / `INPUT_LB_X_SEND_TICKS` | 过滤、合成后本地发送函数接受对应组合的报告帧数，非云端回执 |

两阶段时钟不同，计数不能要求相等，也不是按下次数。采集有、发送没有时先查本地
接管/路由；两者都有但游戏不响应时继续查游戏内键位与远端输入处理，不误称成网络或体感已修好。
新事件提供中文翻译并加入安全监控白名单与保留证据集。
