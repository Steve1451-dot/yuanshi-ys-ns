# 圆石启动器 0.2.147 alpha

2026-11-15（Asia/Singapore）。恢复 ys 原有的即时体感响应，不保留 0.2.146 的启动/恢复等待。

## 本版变化

- 撤销新增的 100 毫秒体感启动与恢复等待。按住实体 ZL 且传感器、输入通道可用时，
  当前输入周期即可合成右摇杆，不推迟按键或物理摇杆。
- 保留原有 LB 优先规则：按住实体 L 时暂停体感，松开后立即恢复，不额外等待。
- 保留移除左下角“原生手柄直通 / 等待云端确认”状态条的改动。
- 保留触屏悬浮球、透明延迟显示、安全日志、原生 Xbox 路线及游戏内键位保存。
- 保留 LB+B / LB+X 的采集与本地发送计数及中文说明；计数并非云端响应确认。
- 不改灵敏度、轴方向、原有传感器新鲜度检查或其他游戏的输入和画质设置。

注意：代码中原有的 **100 毫秒传感器新鲜度上限**仍然保留，用于拒绝过期六轴样本，
它不是体感启动延迟。当前标准 Xbox 物理位置下，游戏 LB+B / LB+X 对应 Switch L+A / L+Y。

## 相对上次公开源码的累计更新

本次同时提交此前 0.2.113–0.2.145 的本地开发进度，使公开源码与当前 NRO 保持一致：
游戏 SDK 配置保存/恢复、键位 XML 格式修复、移动端触屏入口、输入路由恢复、安全日志与
诊断改进，以及既有音频抖动缓冲和媒体互通修复。不重新加入已移除的本地战斗改键预设。

## 安装与数据

下载本版 NRO 或完整 ZIP。新安装使用 `switch/yuanshi-launcher/`；更新仅替换程序，
保留账号、`game-sdk-data.key`、游戏配置及体感设置，不需要重新配置键位。
压缩包不包含 APK、模拟器密钥、账号、登录凭据、测试运行记录或抓包数据。

运行时生成的登录库、密钥、配置快照与结构报告只应留在自己的设备上，不要提交到 GitHub。
根目录 `send-to-switch.bat` 可复制带版本号的新 NRO，并回读校验，保留设备上的旧 NRO。

## 验证范围

本地回归包含首次输入即时响应、LB 松开即恢复、LB+B/LB+X 两种按下/松开顺序、
65,536 种按钮组合、传感器校验与物理摇杆优先；生产 Session 测试覆盖实际移动终端类型 3。
23 项相关主机测试与实际 Switch NRO 构建通过，详情及校验值见
[构建校验](yuanshi-launcher-0.2.147-build.md)；本版不把报文发送成功称为所有游戏动作均已验收。
bt 仍在适配，在线服务可用性、网络表现及不同机型长期运行仍受实际环境影响。
