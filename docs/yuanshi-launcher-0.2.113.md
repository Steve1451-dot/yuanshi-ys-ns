# 圆石启动器 0.2.113 alpha

## 本版目标

保留游戏内修改的原生手柄动作绑定，而不是保存“本地映射／原生”模式作为替代。
本版补齐一个已确认的 SDK 配置存储缺口；尚不能声称游戏内键位已经跨云主机恢复。

## 游戏自身配置保存

- 官方 Android 7.1.0 参考实现：`BaseSdkHolder.interceptGameData` 的
  `cloud_set_data` 按键名调用 `p089g4.C.i`，后者在专用线程写文件；
  `cloud_get_data` 通过 `C.e` 读取。不是接管或快照云主机内存。
- 本项目此前 `Bridge::DispatchCustom` 只有进程内 JSON，没有跨会话存储。
- 本版仅对 ys 启用按官方 Android 语义的逐键合并，不让一个无关配置更新抹掉另一个键。
  bt 和其他兼容应用保留此前的 SDK 回包语义。
- 只接受已在旧会话元数据中出现的 `cloud_local_data_<数字>` 字符串，不保存
  `account_id`、登录回包或任意文件名。数据保持原样，不反序列化成自行猜测的按键表。
- 账号、渠道和应用构成隔离域；文件名使用本地随机密钥的 HMAC，不暴露账号编号。
  AES-256-GCM 认证加密，单份明文上限 256 KiB，最多 32 个缓存键。
- 程序启动 peer 前读取；SDK 回调只入队，独立线程以 500ms 固定窗口合并突发更新，
  失败退避，停止 peer 后刷新最后一份待写数据。不会在媒体回调中写 SD 卡。
- 两个轮换快照保留可恢复版本，密钥也保留备份。无法解密时不覆盖未知原文件。
  这些文件只位于当前 `AppHomePath()`，不查找或迁移旧安装目录。

文件前缀为 `game-sdk-hk4e-`，密钥文件为 `game-sdk-data.key` 及其备份。
加密主要避免配置以明文散落；密钥与密文都在 SD 卡，不是硬件密钥库，
拥有整张卡的人仍可能读取数据。不要把这些文件上传到 GitHub 或当作日志发送。

安全日志只写固定事件，不写键名、内容、账号或密文：

| 事件 | 能说明什么 |
| --- | --- |
| `GAME_SDK_CLOUD_DATA_STORED` | 本次 SDK 配置已更新到内存，不等于写盘 |
| `GAME_SDK_CLOUD_DATA_PERSISTED` | 后台写盘成功 |
| `GAME_SDK_CLOUD_DATA_RESTORED` | 下次会话读回了认证通过的存储 |
| `GAME_SDK_CLOUD_DATA_READ_HIT` | 游戏请求读取的键命中了缓存，不等于游戏接受了键位 |
| `GAME_SDK_CLOUD_DATA_SAVE_FAILED` | 写盘失败，保留旧快照 |
| `GAME_SDK_CLOUD_DATA_RESTORE_FAILED` | 文件无法读取或解密，未覆盖 |

事件按类别限制频率，不增加正常游玩的逐包或逐帧日志。

## 移除本地改键

- ys、zmd、bt 不再提供本地按键映射编辑器、手柄图改键、战斗预设或原生／本地模式切换。
- 不读取 `controller-mapping-*.txt` 或 `genshin-gamepad-mode.txt`；不会替用户删除旧文件。
- 保留既有标准 Xbox 位置编码、触屏入口、输入释放／换源中性帧、地图 `−` 和诊断组合键。
- ys 的实体 ZL 体感转右摇杆单独保留，设置文件改为 `genshin-gyro.txt`；
  无效旧文件不导入。体感可在悬浮球中关闭，按 L 轮盘或本地 UI 捕获时抑制。
- 不更改登录、排队、画质、帧率请求或解码协议，也不保存云主机内存。

## 验收边界

主机测试验证的是真实 SDK 编解码往返和本地持久化，不是假装进入游戏。
必须在 Switch 用同一账号：游戏内改一个明显动作键 → 正常结束串流 → 完全退出启动器
→ 再启动并进入游戏，确认游戏内动作与设置页都保持。仅看到写盘、恢复或读取命中事件不足以验收。

如果这三步存储事件齐全但动作仍重置，说明还需查游戏未导出的设置或其他保存流程，
不能继续把问题归咎于“本地映射没保存”，也不能宣称云主机可继承内存。

本版构建及回归结果完成后记录于交付说明；Switch 原生键位跨会话结果仍未验证。
