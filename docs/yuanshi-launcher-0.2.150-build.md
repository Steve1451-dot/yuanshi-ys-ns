# 0.2.150 构建与验证

2026-11-16（Asia/Singapore）。本版为自动恢复候选，尚未进行新版 Switch 弱网游戏验收。

- devkitA64 / libnx 实际完整 Switch 构建通过，最终源文件改动后再次依赖重编译、链接和生成 NRO。
- NRO0、ASET、嵌入图标、16 语言名称/作者及 NACP 版本均已校验。
- 原生手柄固定/XML、即时体感、Xbox 输入、输入路由、设置持久化、UI、码率/帧率策略回归通过。
- 生产 Session + WebSocket 的 13 个故障注入场景通过：保留媒体重连、重建媒体、授权拒绝、
  服务器结束、三次失败耗尽、TLS 失败、取消并回收线程、恢复期换 ICE、媒体证书失败、
  初始协议错误、只有授权无画面的超时后重建、控制通道失效恢复，以及恢复期协议错误。

- 自动帧率发送分支已删除；持续损伤、码率下限与解码拥塞不再覆盖手动 60 FPS。
  手动 30 FPS 不自动升为 60，码率保护及上限恢复仍有回归。
- 安全监控、固定移动入口、体感组合键、MTP 非覆盖部署 PowerShell 检查通过。
  监控不会把已完成恢复继续误标为永久失败，也不会用恢复事件掩盖授权拒绝。
- Bash 测试入口语法检查通过；不据此声称 GitHub Actions 或在线服务互通已验证。
